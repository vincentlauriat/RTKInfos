Built for RTK — saves 60–90% of Claude API tokensConçu pour RTK — économise 60 à 90 % des tokens de l'API Claude專為 RTK 打造——節省 60–90% 的 Claude API token

Your token savings, live in the menu bar.Vos économies de tokens, en direct dans la barre de menus.你的 token 節省量，即時在選單列。

RTK quietly cuts your Claude API token use by 60–90%. RTKInfos turns that into something you can see — a compression gauge, a 7-day trend and a live command trace, one click from the menu bar.RTK réduit discrètement votre consommation de tokens de l'API Claude de 60 à 90 %. RTKInfos rend cela visible — une jauge de compression, une tendance sur 7 jours et une trace des commandes en direct, à un clic de la barre de menus.RTK 默默地把你的 Claude API token 用量降低 60–90%。RTKInfos 把這件事變成看得見的東西——壓縮量表、7 天趨勢與即時指令紀錄，在選單列點一下就到。

Everything RTK saves, made visibleTout ce que RTK économise, rendu visible把 RTK 省下的一切，變成看得見的

A tiny native menu bar app that reads RTK's local database and turns raw numbers into a glanceable picture of your savings.Une petite app native en barre de menus qui lit la base locale de RTK et transforme les chiffres bruts en une image lisible d'un coup d'œil.一個小巧的原生選單列應用程式，讀取 RTK 的本機資料庫，把原始數字變成一眼就懂的節省全貌。

  • Real-time monitoringSurveillance en temps réel即時監控

    Watches RTK's history.db via FSEvents, with a polling fallback — updates the moment a command runs.Surveille le history.db de RTK via FSEvents, avec repli sur du polling — se met à jour dès qu'une commande tourne.透過 FSEvents 監看 RTK 的 history.db，並以輪詢作為備援——指令一執行就更新。

  • Compression gaugeJauge de compression壓縮量表

    The signature view: raw input compressed down to output, with the reclaimed tokens highlighted in emerald.La vue signature : l'entrée brute compressée vers la sortie, avec les tokens récupérés surlignés en émeraude.招牌視圖：原始輸入壓縮成輸出，並以翡翠綠標出省回來的 token。

  • 7-day trendTendance sur 7 jours7 天趨勢

    Your daily savings, color-encoded by intensity, so you can spot the pattern at a glance.Vos économies quotidiennes, encodées en couleur par intensité, pour repérer la tendance d'un coup d'œil.每日節省量以色彩深淺編碼，讓你一眼看出規律。

  • Live TraceTrace en direct即時紀錄

    A streaming side panel of your latest commands, newest first, each with its savings.Un panneau latéral en flux de vos dernières commandes, les plus récentes en premier, chacune avec son économie.側邊即時面板列出你最新的指令，最新的在最上面，每一筆都附上節省量。

  • Status alertsAlertes d'état狀態警示

    Detects a missing RTK install or more than 7 days of inactivity, and tells you.Détecte une installation RTK manquante ou plus de 7 jours d'inactivité, et vous le signale.偵測到 RTK 未安裝或超過 7 天沒有活動時，會通知你。

  • PreferencesPréférences偏好設定

    Launch at login, configurable polling interval and a custom database path.Lancement à l'ouverture de session, intervalle de polling configurable et chemin de base personnalisé.開機時啟動、可設定的輪詢間隔，以及自訂資料庫路徑。

Numbers you'd otherwise never seeDes chiffres que vous ne verriez jamais autrement你原本永遠看不到的數字

RTK does its work silently in the background. RTKInfos sits read-only on top of its database — a single @Observable source of truth driving a native SwiftUI dashboard — so the savings RTK earns you become tangible, day after day.RTK fait son travail silencieusement en arrière-plan. RTKInfos se pose en lecture seule au-dessus de sa base — une unique source de vérité @Observable qui alimente un tableau de bord SwiftUI natif — pour rendre tangibles, jour après jour, les économies que RTK vous fait gagner.RTK 在背景默默運作。RTKInfos 以唯讀方式架在它的資料庫之上——單一的 @Observable 真實來源驅動原生 SwiftUI 儀表板——讓 RTK 為你省下的量，一天一天變得具體可見。

Up and running in a minuteOpérationnel en une minute一分鐘內開始使用

RTKInfos reads the database that RTK already keeps — so once RTK is set up, there's nothing else to configure.RTKInfos lit la base que RTK tient déjà — une fois RTK configuré, il n'y a rien d'autre à régler.RTKInfos 讀取 RTK 本來就在維護的資料庫——只要 RTK 設定好了，就沒有別的要設定。

  1. Have RTK installed. RTKInfos visualizes RTK's data, so install and configure it first.Avoir RTK installé. RTKInfos visualise les données de RTK : installez-le et configurez-le d'abord.先安裝 RTK。RTKInfos 視覺化的是 RTK 的資料，請先安裝並設定它。

  2. Download & install. Grab the latest .dmg and drag RTKInfos.app into /Applications.Télécharger et installer. Récupérez le dernier .dmg et glissez RTKInfos.app dans /Applications.下載並安裝。取得最新的 .dmg，把 RTKInfos.app 拖入 /Applications。

  3. Launch. Open it — the icon lands in your menu bar. Enable Launch at Login from Preferences.Lancer. Ouvrez-la — l'icône apparaît dans la barre de menus. Activez Lancement à l'ouverture de session dans les Préférences.啟動。開啟它——圖示會出現在選單列。可在偏好設定中啟用開機時啟動。
